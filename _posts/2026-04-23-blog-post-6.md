I recently took a course on "Power System Stability and Control," and an interesting question suddenly struck me. This post studies this simple but important question in a single-machine infinite-bus system:

> What changes when the excitation system is changed from proportional voltage feedback to PI voltage feedback?

The main conclusion is that integral action removes the terminal-voltage steady-state error. In the simulation below, the proportional AVR gives a stable equilibrium with terminal voltage about 0.8097, while the PI AVR moves the terminal voltage exactly to the reference value 0.9. The cost is that the PI controller introduces an additional slow pole. In this example, that slow pole mainly affects the excitation and voltage-related states, such as the integral state, excitation voltage, internal voltage, and terminal voltage. It is not primarily a frequency oscillation mode, although the frequency state can still be weakly affected through coupling.

The analysis compares two cases:

1. AVR with proportional voltage feedback only.
2. AVR with PI voltage feedback.

The comparison is based on nonlinear equilibrium calculation, small-signal linearization, eigenvalue analysis, and the transfer function from the excitation input <em>u</em> to the rotor speed deviation <em>ω</em>.

## 1. SMIB Model Setup

Before adding integral action, define the state vector as follows:

<div class="eq eq-center">
<em>x</em> = [ <em>E</em><sub>fd</sub>, <em>e</em>, <em>δ</em>, <em>ω</em> ]<sup>T</sup>
</div>

Here, <em>E</em><sub>fd</sub> is the excitation voltage state, <em>e</em> is the internal transient voltage magnitude, <em>δ</em> is the rotor angle, and <em>ω</em> is the rotor speed deviation.

The terminal voltage magnitude is computed from

<div class="eq eq-center">
<em>V</em> = sqrt( <em>α</em><sup>2</sup><em>e</em><sup>2</sup> + 2<em>αβe</em> cos<em>δ</em> + <em>β</em><sup>2</sup> ).
</div>

The network constants are

<div class="eq eq-center">
<em>α</em> = <em>x</em><sub>L</sub> / (<em>x</em> + <em>x</em><sub>L</sub>), &nbsp;&nbsp;
<em>β</em> = <em>x</em> / (<em>x</em> + <em>x</em><sub>L</sub>).
</div>

The network angle is

<div class="eq eq-center">
<em>θ</em> = tan<sup>−1</sup>{ <em>αe</em> sin<em>δ</em> / (<em>αe</em> cos<em>δ</em> + <em>β</em>) }.
</div>

In numerical implementation, it is usually better to compute this angle with `atan2` rather than `atan`, because `atan2` handles the quadrant correctly. The expression above is the mathematical form used in the simulation.

The machine and excitation dynamics are

<div class="eq">
<strong>Excitation voltage:</strong><br>
d<em>E</em><sub>fd</sub>/dt = (1/<em>T</em><sub>d0</sub>′)[ −<em>K</em><sub>1</sub><em>E</em><sub>fd</sub> − <em>K</em><sub>2</sub>(<em>V</em> − <em>V</em><sup>*</sup>) + <em>u</em> ].
</div>

<div class="eq">
<strong>Internal voltage:</strong><br>
d<em>e</em>/dt = (1/<em>T</em><sub>d</sub>)[ −<em>a e</em> + <em>b V</em> cos(<em>δ</em> − <em>θ</em>) + <em>E</em><sub>fd</sub> ].
</div>

<div class="eq eq-center">
d<em>δ</em>/dt = <em>ω</em>.
</div>

<div class="eq">
<strong>Rotor speed deviation:</strong><br>
d<em>ω</em>/dt = (1/<em>M</em>)[ <em>P</em><sub>m</sub> − <em>dω</em> − <em>eV</em> sin(<em>δ</em> − <em>θ</em>)/<em>x</em> ].
</div>

The constants in the transient-voltage equation are

<div class="eq eq-center">
<em>a</em> = <em>x</em><sub>d</sub>/<em>x</em>′<sub>d</sub>, &nbsp;&nbsp;
<em>b</em> = (<em>x</em><sub>d</sub> − <em>x</em>′<sub>d</sub>)/<em>x</em>′<sub>d</sub>.
</div>

The parameter values used in the simulation are

<div class="eq eq-center">
<em>T</em><sub>d0</sub>′ = 0.1, &nbsp;
<em>T</em><sub>d</sub> = 0.05, &nbsp;
<em>K</em><sub>1</sub> = 1.5, &nbsp;
<em>K</em><sub>2</sub> = 6,
<br>
<em>M</em> = 0.2, &nbsp;
<em>d</em> = 0.28, &nbsp;
<em>P</em><sub>m</sub> = 0.1, &nbsp;
<em>V</em><sup>*</sup> = 0.9.
</div>

## 2. Excitation System Without PI Control

Without integral action, the excitation equation is

<div class="eq eq-center">
d<em>E</em><sub>fd</sub>/dt = (1/<em>T</em><sub>d0</sub>′)[ −<em>K</em><sub>1</sub><em>E</em><sub>fd</sub> − <em>K</em><sub>2</sub>(<em>V</em> − <em>V</em><sup>*</sup>) + <em>u</em> ].
</div>

For the equilibrium calculation in this post, take <em>u</em> = 0. At equilibrium, d<em>E</em><sub>fd</sub>/dt = 0. Therefore,

<div class="eq eq-center">
0 = −<em>K</em><sub>1</sub><em>E</em><sub>fd</sub> − <em>K</em><sub>2</sub>(<em>V</em> − <em>V</em><sup>*</sup>).
</div>

Solving this equation gives

<div class="eq eq-center">
<em>K</em><sub>1</sub><em>E</em><sub>fd</sub> = −<em>K</em><sub>2</sub>(<em>V</em> − <em>V</em><sup>*</sup>),
</div>

or equivalently,

<div class="eq eq-center">
<em>E</em><sub>fd</sub> = −(<em>K</em><sub>2</sub>/<em>K</em><sub>1</sub>)(<em>V</em> − <em>V</em><sup>*</sup>)
= (<em>K</em><sub>2</sub>/<em>K</em><sub>1</sub>)(<em>V</em><sup>*</sup> − <em>V</em>).
</div>

This is the key point. The proportional AVR does not impose <em>V</em> = <em>V</em><sup>*</sup>. Instead, the excitation voltage <em>E</em><sub>fd</sub> balances the proportional voltage error. Therefore, a proportional AVR can stabilize the voltage, but it generally leaves a nonzero steady-state voltage error.

The computed equilibrium is

<div class="matrix-block">
<pre>x_e, no PI =
[ 0.361147998565988
  0.678486721654244
  0.648869391580794
  0 ]

V_e, no PI = 0.809713000359</pre>
</div>

Because <em>V</em><sub>e,no PI</sub> is not equal to <em>V</em><sup>*</sup>, the proportional controller has a steady-state voltage error:

<div class="eq eq-center">
<em>V</em><sup>*</sup> − <em>V</em><sub>e,no PI</sub> = 0.9 − 0.809713000359 ≈ 0.090287.
</div>

## 3. Excitation System With PI Control

After adding integral action, introduce a new integral state <em>W</em><sub>1</sub>:

<div class="eq eq-center">
d<em>W</em><sub>1</sub>/dt = <em>V</em> − <em>V</em><sup>*</sup>.
</div>

The state vector becomes

<div class="eq eq-center">
<em>x</em><sub>PI</sub> = [ <em>E</em><sub>fd</sub>, <em>e</em>, <em>δ</em>, <em>ω</em>, <em>W</em><sub>1</sub> ]<sup>T</sup>.
</div>

The excitation equation becomes

<div class="eq eq-center">
d<em>E</em><sub>fd</sub>/dt = (1/<em>T</em><sub>d0</sub>′)[ −<em>K</em><sub>1</sub><em>E</em><sub>fd</sub> − <em>K</em><sub>2</sub>(<em>V</em> − <em>V</em><sup>*</sup>) − <em>K</em><sub>3</sub><em>W</em><sub>1</sub> + <em>u</em> ].
</div>

In the simulation, <em>K</em><sub>3</sub> = 0.5. At equilibrium, the integral equation gives

<div class="eq eq-center">
d<em>W</em><sub>1</sub>/dt = 0.
</div>

Since d<em>W</em><sub>1</sub>/dt = <em>V</em> − <em>V</em><sup>*</sup>, the equilibrium must satisfy

<div class="eq eq-center">
<em>V</em><sub>e</sub> = <em>V</em><sup>*</sup>.
</div>

This is the most important difference between P control and PI control. The additional state <em>W</em><sub>1</sub> forces the steady-state voltage error to zero.

The computed equilibrium is

<div class="matrix-block">
<pre>x_e, PI =
[ 0.770015681067331
  0.846375002432449
  0.5056987424032
  0
 -2.31004704320199 ]

V_e, PI = 0.900000000000</pre>
</div>

Thus the PI controller changes the equilibrium significantly. Compared with the proportional AVR, the PI AVR requires a larger excitation voltage <em>E</em><sub>fd</sub>, a larger internal voltage <em>e</em>, and a smaller rotor angle <em>δ</em>. The terminal voltage is restored exactly to <em>V</em><sup>*</sup> = 0.9.

## 4. Small-Signal Linearization

Let the nonlinear system be written as

<div class="eq eq-center">
d<em>x</em>/dt = <em>f</em>(<em>x</em>, <em>u</em>).
</div>

Linearizing around the equilibrium (<em>x</em><sub>e</sub>, <em>u</em><sub>e</sub>) gives

<div class="eq eq-center">
Δ(d<em>x</em>/dt) = <em>A</em>Δ<em>x</em> + <em>B</em>Δ<em>u</em>,
</div>

where

<div class="eq eq-center">
<em>A</em> = ∂<em>f</em>/∂<em>x</em> evaluated at (<em>x</em><sub>e</sub>, <em>u</em><sub>e</sub>), &nbsp;&nbsp;
<em>B</em> = ∂<em>f</em>/∂<em>u</em> evaluated at (<em>x</em><sub>e</sub>, <em>u</em><sub>e</sub>).
</div>

The terminal-voltage output is linearized as

<div class="eq eq-center">
Δ<em>V</em> = <em>C</em><sub>V</sub>Δ<em>x</em> + <em>D</em><sub>V</sub>Δ<em>u</em>,
</div>

where <em>C</em><sub>V</sub> is the gradient of <em>V</em> with respect to the states, evaluated at the equilibrium.

The frequency output is simply the fourth state:

<div class="eq eq-center">
<em>C</em><sub>ω,no PI</sub> = [0, 0, 0, 1], &nbsp;&nbsp;
<em>C</em><sub>ω,PI</sub> = [0, 0, 0, 1, 0].
</div>

## 5. Linearized Model Without PI

The linearized matrices for the proportional AVR are

<pre>A_noPI =

  19.9999999994649   -73.6585365856968   -32.4251002936649     0
   0                   0                   0                   1
   0                  -0.736934097599062  -0.659263636008933  -1.40000000002638

  0
  0

C_V_noPI =
 0    0.424635095919168   -0.125910315729172    0

C_omega_noPI =
 0    0    0    1</pre>
</div>

The eigenvalues are

<div class="eq eq-center">
λ(<em>A</em><sub>no PI</sub>) = { −63.0461, −25.6195, −0.6965 + j0.1446, −0.6965 − j0.1446 }.
</div>

The first two real poles are fast electrical or excitation-related modes. The complex pair is the dominant electromechanical mode in this operating condition.

For the complex pair

<div class="eq eq-center">
λ = −0.6965 ± j0.1446,
</div>

its natural frequency and damping ratio are approximately

<div class="eq eq-center">
ω<sub>n</sub> = sqrt(0.6965<sup>2</sup> + 0.1446<sup>2</sup>) ≈ 0.7113,
&nbsp;&nbsp;
ζ = 0.6965 / 0.7113 ≈ 0.979.
</div>

The transfer function from <em>u</em> to <em>ω</em> is

<div class="eq eq-center">
<em>G</em><sub>u→ω,no PI</sub>(s) = −147.39s / [(s + 63.05)(s + 25.62)(s<sup>2</sup> + 1.393s + 0.506)].
</div>

The numerator contains a zero at s = 0, so a constant change in the excitation input does not create a nonzero steady-state frequency deviation. This is consistent with the fact that the steady-state rotor speed deviation should return to zero in a stable synchronous operating point.

## 6. Linearized Model With PI

The linearized matrices for the PI AVR are

<div class="matrix-block">
<pre>A_PI =

  20.0000000005751   -73.6585365856968    -25.9932062451895     0                   0
   0                   0                    0                   1                   0
   0                  -0.590754687494754   -0.9029749930764    -1.40000000002638    0
   0                   0.443666408334042   -0.11327913279624    0                   0

B_PI =
 10
  0
  0
  0
  0

C_V_PI =
 0    0.443666408334042   -0.11327913279624    0    0

C_omega_PI =
 0    0    0    1    0</pre>
</div>

The eigenvalues are

<div class="eq eq-center">
λ(<em>A</em><sub>PI</sub>) = { −62.4484, −26.1878, −0.6933 + j0.5644, −0.6933 − j0.5644, −0.03578 }.
</div>

The most important new feature is the additional real pole

<div class="eq eq-center">
λ<sub>slow</sub> = −0.03578.
</div>

Its approximate time constant is

<div class="eq eq-center">
τ<sub>slow</sub> ≈ 1 / 0.03578 ≈ 27.95 s.
</div>

This time constant is much larger than those associated with the two fast electrical modes. Therefore, the PI controller introduces a slow tail in the response.

For the complex pair with PI control,

<div class="eq eq-center">
λ = −0.6933 ± j0.5644,
</div>

we get

<div class="eq eq-center">
ω<sub>n</sub> = sqrt(0.6933<sup>2</sup> + 0.5644<sup>2</sup>) ≈ 0.8940,
&nbsp;&nbsp;
ζ = 0.6933 / 0.8940 ≈ 0.775.
</div>

Thus the electromechanical pair has a higher oscillation frequency and a lower damping ratio after adding PI control in this parameter setting. However, this does not mean the added slow pole is a frequency oscillation mode. The slow pole is real and is mainly associated with the integral-voltage regulation channel.

The transfer function from <em>u</em> to <em>ω</em> is

<div class="eq eq-center">
<em>G</em><sub>u→ω,PI</sub>(s) = −118.15s<sup>2</sup> / [(s + 62.45)(s + 26.19)(s + 0.03578)(s<sup>2</sup> + 1.387s + 0.7991)].
</div>

The PI case has one more pole because the integral state <em>W</em><sub>1</sub> adds one more system state.

## 7. Why PI Removes Voltage Steady-State Error

The reason is very direct. With PI control,

<div class="eq eq-center">
d<em>W</em><sub>1</sub>/dt = <em>V</em> − <em>V</em><sup>*</sup>.
</div>

At equilibrium, every state derivative must be zero. Hence,

<div class="eq eq-center">
0 = d<em>W</em><sub>1</sub>/dt = <em>V</em><sub>e</sub> − <em>V</em><sup>*</sup>.
</div>

Therefore,

<div class="eq eq-center">
<em>V</em><sub>e</sub> = <em>V</em><sup>*</sup>.
</div>

This result does not depend on the detailed values of <em>K</em><sub>1</sub>, <em>K</em><sub>2</sub>, or <em>K</em><sub>3</sub>, as long as a stable equilibrium exists and the integral state is not saturated.

Without PI control, the excitation equation only gives

<div class="eq eq-center">
<em>E</em><sub>fd,e</sub> = (<em>K</em><sub>2</sub>/<em>K</em><sub>1</sub>)(<em>V</em><sup>*</sup> − <em>V</em><sub>e</sub>).
</div>

This relation allows <em>V</em><sub>e</sub> ≠ <em>V</em><sup>*</sup>. The proportional controller can only make the voltage error small by increasing the proportional gain. It cannot force the error to zero unless special conditions happen to hold.

---

## 8. Which Quantity Becomes Slow After Adding PI?

The additional slow pole is associated primarily with the integral-voltage regulation loop.

The signal chain is

<div class="eq eq-center">
<em>V</em> − <em>V</em><sup>*</sup> → <em>W</em><sub>1</sub> → <em>E</em><sub>fd</sub> → <em>e</em> → <em>V</em>.
</div>

Therefore, the slow tail should be most visible in the following variables:

1. <em>W</em><sub>1</sub>, the integral state.
2. <em>E</em><sub>fd</sub>, the excitation voltage state.
3. <em>e</em>, the internal transient voltage magnitude.
4. <em>V</em>, the terminal voltage magnitude.

The rotor speed deviation <em>ω</em> can still contain a small component of this slow mode because the full nonlinear system is coupled. However, the main oscillatory behavior of <em>ω</em> is still governed by the electromechanical complex pair, not by the new real slow pole.

In this example, the extra pole is

<div class="eq eq-center">
−0.03578,
</div>

while the electromechanical pair is approximately

<div class="eq eq-center">
−0.6933 ± j0.5644.
</div>

The real part of the electromechanical pair is much more negative than the slow pole. Hence, the oscillatory part decays much faster than the slow integral-voltage correction.

## 9. Root Locus Interpretation for u → ω

For the root-locus study, the input is the excitation-side input <em>u</em>, and the output is the frequency state <em>ω</em>. Therefore, the SISO systems are

<div class="eq eq-center">
<em>G</em><sub>u→ω,no PI</sub>(s) = <em>C</em><sub>ω,no PI</sub>(s<em>I</em> − <em>A</em><sub>no PI</sub>)<sup>−1</sup><em>B</em><sub>no PI</sub>,
</div>

and

<div class="eq eq-center">
<em>G</em><sub>u→ω,PI</sub>(s) = <em>C</em><sub>ω,PI</sub>(s<em>I</em> − <em>A</em><sub>PI</sub>)<sup>−1</sup><em>B</em><sub>PI</sub>.
</div>

The no-PI model is fourth order, while the PI model is fifth order. Therefore, the PI root locus has one additional open-loop pole. That additional pole appears near the origin at −0.03578, which reflects the slow integral mode.

This is why, after adding PI control, the root locus is not just a small perturbation of the original one. The order of the system changes, and the new pole changes the low-frequency behavior of the excitation-to-frequency transfer function.

---

## 10. Summary

Adding PI control to the excitation system changes the SMIB model in three main ways.

First, it adds one new state:

<div class="eq eq-center">
d<em>W</em><sub>1</sub>/dt = <em>V</em> − <em>V</em><sup>*</sup>.
</div>

Second, it changes the equilibrium constraint. Without PI, the proportional AVR allows a nonzero voltage error:

<div class="eq eq-center">
<em>V</em><sub>e,no PI</sub> = 0.809713 ≠ 0.9.
</div>

With PI, the integral equation enforces

<div class="eq eq-center">
<em>V</em><sub>e,PI</sub> = <em>V</em><sup>*</sup> = 0.9.
</div>

Third, it introduces an additional slow pole:

<div class="eq eq-center">
λ<sub>slow</sub> = −0.03578.
</div>

This slow pole mainly affects the voltage-regulation channel, especially <em>W</em><sub>1</sub>, <em>E</em><sub>fd</sub>, <em>e</em>, and <em>V</em>. It is not mainly a frequency oscillation mode. The rotor speed <em>ω</em> is still mainly shaped by the electromechanical complex pair, although weak coupling means that <em>ω</em> may also contain a small slow component.

In short, PI control improves steady-state voltage tracking, but it adds a slow integral mode. This is the classical tradeoff: better steady-state accuracy at the cost of slower low-frequency transient behavior.
